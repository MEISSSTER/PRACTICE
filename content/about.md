## Что такое Mini Pixel

**Mini Pixel** — это проект по созданию миниатюрного принтера с нуля. Разработка ведётся в рамках направления **NeoPixel** как часть проектной практики первого курса.

Принтер управляется микроконтроллером **ESP32-S3**, прошивка пишется на языке **C/C++** в среде **Visual Studio Code** с расширением **PlatformIO**.

---

## Цели проекта

- **Разработать рабочий прототип миниатюрного фотополимерного принтера**
- Освоить наывки командной работы
- Освоить наывки 3D моделирования
- Освоить программирование микроконтроллеров на C/C++
- Научиться работать с периферией: дисплеями, шаговыми двигателями, реле
- Получить навыки симуляции схем в Proteus
- Получить навыки работы с программным обеспечением для создания печатных плат
- Освоить командную работу через Git и GitHub

## Этапы реализации

## Этап 1 — Подготовка (выполнено)
- Выбор компонентов
- Изучение документации
- Настройка рабочего окружения (VS Code, PlatformIO, Git).

## Этап 2 — Прошивка (в процессе)
### Написание кода для ESP32-S3: 
- Инициализация дисплеев
- Управление шаговым двигателем через драйвер
- Логика печати.

### Этап 3 — Тестирование схемы  (в процессе)
- Симуляция работы элементов
- Сборка отдельных узлов притера для отладки
- Подготовка нового корпуса для принтера

### Этап 4 — Физическая сборка (планируется)
- Сборка устройства на макетной плате
- Настройка и калибровка.

### Этап 5 — Финальное тестирование (планируется)
Комплексное тестирование, устранение ошибок, документирование результатов.
