## Команда проекта

### 👤 Участник 1

**Роль:** Разработчик прошивки, технический лид

**Вклад в проект:**

- Написание прошивки на C для ESP32-S3
- Настройка рабочего окружения (VS Code, PlatformIO)
- Инициализация и настройка дисплеев ILI9488
- Реализация управления шаговым двигателем через драйвер A4988
- Симуляция схемы в Proteus
- Ведение репозитория на GitHub
- Написание технической документации

**Инструменты:** C, PlatformIO, Git, Proteus, VS Code
