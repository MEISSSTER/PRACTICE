## Список компонентов

Все компоненты подобраны с учётом совместимости и доступности. Ниже — полная таблица с описанием и ссылками на документацию.

---

### Микроконтроллер

#### ESP32-S3

Основа всего проекта. Двухъядерный процессор Xtensa LX7, Wi-Fi + Bluetooth, логика 3.3В.

![ESP32-S3](/img/esp32.png)

| Параметр | Значение |
|---|---|
| Напряжение питания | 3.3В |
| Ядра | 2 × Xtensa LX7 |
| Частота | до 240 МГц |
| Flash | 8 МБ (зависит от платы) |
| Интерфейсы | SPI, I2C, UART, PWM |

>  Вся периферия должна работать на **3.3В** или иметь преобразователь уровней.

[Datasheet ESP32-S3](https://www.espressif.com/sites/default/files/documentation/esp32-s3_datasheet_en.pdf)

###  Дисплеи

#### ILI9488 × 2

Два TFT-дисплея подключаются по SPI. В Proteus используется аналог ILI9341. Каждый дисплей требует **отдельного CS (Chip Select)**.

![ILI9488](/img/tft.jpg)

| Параметр | Значение |
|---|---|
| Интерфейс | SPI |
| Разрешение | 320 × 480 |
| Питание | 3.3В |
| Подключение | разные пины CS |

[Datasheet ILI9488](https://www.displayfuture.com/Display/Datasheet/Controller/ILI9488.pdf)

###  Движение

#### Шаговый двигатель NEMA17 17mm

Отвечает за механическое перемещение печатающей головки. Требует внешнего драйвера.

![NEMA17](/img/NEMA17-04-02.png)

| Параметр | Значение |
|---|---|
| Тип | Шаговый, биполярный |
| Шаг | 1.8° (200 шагов/оборот) |
| Питание | 12В / 24В |
| Ток | до 2А |

[ Спецификация NEMA17](https://www.reprap.org/wiki/NEMA_17_Stepper_motor)

#### Драйвер A4988 / TMC2209

Управляет шаговым двигателем, получая сигналы STEP и DIR от ESP32-S3. TMC2209 тише и поддерживает UART.

![A4988](/img/a4988.png)

###  Питание

#### Понижающий модуль LM2596

Преобразует входное напряжение (12В/24В) до 5В для питания реле и других компонентов.

![LM2596](/img/lm2596.png)

| Параметр | Значение |
|---|---|
| Входное напряжение | 4В — 40В |
| Выходное напряжение | настраивается (нужно 5В) |
| Максимальный ток | 3А |

>  **Обязательно** настрой выход на **5В** с помощью подстроечного резистора **до** подключения остальных компонентов.

[ Datasheet LM2596](https://www.ti.com/lit/ds/symlink/lm2596.pdf)

###  Коммутация

#### Реле SONGLE SRD-05VDC-SL-C

Реле на 5В для коммутации нагрузки. Управляется от ESP32-S3 через транзистор с защитным диодом.

| Параметр | Значение |
|---|---|
| Напряжение катушки | 5В |
| Максимальный ток контактов | 10А |
| Управление | через транзистор от ESP32 |

>  Не подключай реле напрямую к ESP32-S3 — используй транзистор (например, BC547) и защитный диод (1N4007) параллельно катушке.

[ Datasheet SONGLE реле](https://html.alldatasheet.com/html-pdf/99638/SONGLE/SRD-05VDC-SL-C/238/1/SRD-05VDC-SL-C.html)

## Схема питания

```
Внешний БП (12В/24В)
        │
        ▼
    LM2596 ──→ 5В ──→ Реле SONGLE
        │              Драйвер мотора
        │
        ▼
   Регулятор 3.3В
        │
        ▼
    ESP32-S3
    ILI9488 × 2
```
