## Управление шаговым двигателем NEMA17

Драйвер **A4988** управляется двумя сигналами от ESP32-S3:

| Сигнал | Описание |
|---|---|
| STEP | Один импульс = один шаг двигателя |
| DIR | Направление вращения (HIGH / LOW) |
| EN | Включение драйвера (LOW = включён) |

### Код управления мотором

```c
#define STEP_PIN 4
#define DIR_PIN  5
#define EN_PIN   6

void motorStep(int steps, bool direction) {
    digitalWrite(DIR_PIN, direction);
    digitalWrite(EN_PIN, LOW);  // включить драйвер

    for (int i = 0; i < steps; i++) {
        digitalWrite(STEP_PIN, HIGH);
        delayMicroseconds(1000);  // скорость: меньше = быстрее
        digitalWrite(STEP_PIN, LOW);
        delayMicroseconds(1000);
    }

    digitalWrite(EN_PIN, HIGH);  // выключить драйвер
}
```

## Схема питания

Настроили **LM2596** на выход 5В. Алгоритм настройки:

1. Подключить вольтметр к выходу LM2596
2. Вращать подстроечный резистор до показания **5.0В**
3. Только после этого подключать нагрузку (реле, драйвер)

### Реле и защита ESP32-S3

Реле нельзя подключать напрямую к GPIO — ESP32-S3 не выдержит ток катушки. Схема управления:

```
GPIO ESP32 ──→ Резистор 1кОм ──→ База BC547
                                  │
                               Коллектор ──→ Катушка реле (−)
                                  │
                                 GEM ──→ GND

Катушка реле (+) ──→ 5В
Параллельно катушке: диод 1N4007 (анод к GND, катод к 5В)
```

## Проблемы и решения

| Проблема | Решение |
|---|---|
| Мотор дёргался и не шёл плавно | Неправильный номинал токоограничивающего резистора на A4988 — пересчитали по формуле из datasheet |
| Реле щёлкало само по себе | Добавили подтягивающий резистор на пин EN реле |
