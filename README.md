## Задание

Задание размещено в папке `task` в файле `README.md`.

### Вариативная часть задания

Тема вариативной части: **«Разработка Telegram-бота "Настюшка" на базе локальной языковой модели Ollama»**.

Бот предназначен для «поддержки» пользователей, однако делает это максимально абсурдным образом: использует актуальный молодёжный сленг и новомодные слова, при этом притворяясь наивным и недалёким. Проект реализован как юмористическое исследование возможностей локальных LLM.


### Проектная деятельность

Проектная (учебная) практика проводилась в связке с выполнением проекта **«NeoPixel — фотополимерный 3D-принтер»** по дисциплине «Проектная деятельность».

Репозиторий проекта: [MEISSSTER/Mini_Pixel_proj](https://github.com/MEISSSTER/Mini_Pixel_proj)

### Период проведения

С **03 февраля 2025 г.** по **24 мая 2025 г.**

## Структура репозитория

```
PRACTICE/
├── assets/             — медиафайлы сайта (изображения, иконки)
├── content/            — контент Hugo-сайта (страницы в формате Markdown)
├── public/             — собранная статическая версия сайта
├── resources/          — сгенерированные ресурсы Hugo (CSS, хэши)
├── static/             — статические файлы (favicon, загружаемые документы)
├── themes/             — тема оформления Hugo (Ananke)
├── reports/            — отчёт по практике (DOCX + PDF)
├── task/               — задание на практику
├── hugo.toml           — конфигурация Hugo-сайта
└── README.md           — описание репозитория (этот файл)
```

## Отчётная часть

### 1. Настройка Git и репозитория

- Создан данный репозиторий `MEISSSTER/PRACTICE` на платформе GitHub на основе предоставленного шаблона.
- Освоены базовые команды Git: `git clone`, `git add`, `git commit`, `git push`, создание и переключение веток.
- Репозиторий содержит **19 коммитов** с осмысленными сообщениями, отражающими этапы работы.
- Параллельно создан и поддерживается репозиторий [MEISSSTER/Mini_Pixel_proj](https://github.com/MEISSSTER/Mini_Pixel_proj) с исходным кодом и технической документацией проекта 3D-принтера NeoPixel.

### 2. Написание документов в Markdown

- Все материалы проекта оформлены в формате Markdown: данный `README.md`, журнал прогресса, технические руководства в `content/`.
- Изучен синтаксис Markdown: заголовки, таблицы, ссылки, блоки кода, изображения.
- Репозиторий проекта `Mini_Pixel_proj` содержит `README.md` с актуальной технической документацией, которая обновлялась на протяжении всего периода практики.

### 3. Создание статического веб-сайта

- Изучены основы HTML5, CSS3 и принципы адаптивной вёрстки.
- Создана первая версия сайта на чистом HTML/CSS — репозиторий [MEISSSTER/MiniSite](https://github.com/MEISSSTER/MiniSite). В ходе работы получены базовые навыки написания HTML и CSS, понимание структуры веб-страниц.
- Освоен генератор статических сайтов **Hugo**: установка, настройка `hugo.toml`, подключение темы Ananke как Git-подмодуля, создание контентных страниц.
- Сайт включает: главную страницу с аннотацией проекта, страницу «О проекте», раздел «Участники», журнал прогресса (не менее трёх записей), страницу «Ресурсы» с полезными ссылками. Все страницы оформлены медиаконтентом.
- Собранный сайт развёрнут на удалённом VPS-сервере с использованием **Nginx** по адресу [http://web-verse.ru](http://web-verse.ru).
